3. Gerenciador Universal de HUD Interativo

Como criar elementos de interface arrastáveis e redimensionáveis pelo jogador.

A Filosofia do IRotaHudElement

Em vez de cada mod inventar um sistema próprio de coordenadas e telas de personalização de HUD, o Rota Core centraliza tudo.

Quando seu mod registra um IRotaHudElement, o jogador ganha automaticamente o poder de abrir a tela RotaHudEditScreen para arrastar seu elemento pela tela com o mouse, mudar a escala, alterar a opacidade e travar em pontos de ancoragem.

1. Implementando o Elemento de HUD

package com.exemplo.mod.client.hud;

import com.rotacore.client.gui.hud.IRotaHudElement;
import com.rotacore.client.gui.hud.RotaHudAnchor;
import net.minecraft.client.gui.GuiGraphics;

public class VelocimetroHudElement implements IRotaHudElement {
    @Override
    public String getId() {
        return "meu_mod:velocimetro";
    }

    @Override
    public int getWidth() {
        return 80;
    }

    @Override
    public int getHeight() {
        return 24;
    }

    @Override
    public RotaHudAnchor getDefaultAnchor() {
        return RotaHudAnchor.BOTTOM_LEFT;
    }

    @Override
    public void render(GuiGraphics graphics, float partialTick) {
        // Seu código de desenho na tela (texturas, textos, valores)
        graphics.drawString(Minecraft.getInstance().font, "120 km/h", 4, 8, 0xFFFFFF);
    }
}

2. Registrando no RotaHudRegistry

RotaHudRegistry.register(new VelocimetroHudElement());

O Rota Core cuidará da persistência em disco das coordenadas escolhidas pelo jogador, sem que você precise escrever uma única linha de código de salvamento.
