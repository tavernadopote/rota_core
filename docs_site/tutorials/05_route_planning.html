5. Planejamento Mestre de Rotas e Grafos Viários

O motor matemático de traçado de rotas por Splines e curvas de nível topográficas.

O Grafo Mestre de Vias (MasterRouteGraph)

O Rota Core mantém a malha teórica de conexões entre vilas, portos, postos avançados e pontos de interesse em um grafo matemático chamado MasterRouteGraph.

Em vez de traçar linhas retas cegas que cortam montanhas ao meio, o Core possui o ContourRoutePlanner, que calcula caminhos suaves acompanhando o relevo natural do terreno.

1. Consultando uma Rota Teórica via Spline

package com.exemplo.mod;

import com.rotacore.world.routes.MasterRouteGraph;
import com.rotacore.world.routes.SplineRoute;
import net.minecraft.core.BlockPos;

public class ConsultaViaria {
    public void obterTrajeto(BlockPos origem, BlockPos destino) {
        // Obtém o traçado suave calculado pelo Core
        SplineRoute rota = MasterRouteGraph.getRouteBetween(origem, destino);

        if (rota != null) {
            System.out.println("Comprimento da rota: " + rota.getLength() + " blocos");
            System.out.println("Nível da via (Tier): " + rota.getTier());

            // Itera pelos pontos de passagem (Waypoints) suavizados
            for (BlockPos ponto : rota.getSampledPoints(1.0f)) {
                // Posição exata calculada com greide suave
            }
        }
    }
}

2. Corpos de Vias (WayBodyType)

O Core categoriza as vias em tipos cadastrais através do WayBodyType:

  • HIGHWAY: Rodovia principal de grande fluxo (geralmente alvenaria de pedra e maior largura).
  • RURAL_PATH: Estrada secundária ou rural (terra batida, cascalho e trilhas).
  • WATERWAY: Hidrovia ou canal de navegação marítimo.
