2. Framework de Telas, Opções e Componentes UI

Como criar telas de configuração padronizadas com layout em 2 colunas e painel lateral Inspector.

A Estrutura de Duas Colunas do Rota Core

O Rota Core padronizou todas as telas de opções do jogo através da classe RotaCategoryScreen:

  • Coluna da Esquerda (~67%): Lista rolável contendo controles interativos (botões, switches, sliders).
  • Coluna da Direita (~33% - Inspector): Painel lateral inteligente que exibe busca, título, descrição aprofundada, avisos e pré-visualização gráfica da opção que estiver com o cursor do mouse posicionado.

1. Registrando uma Categoria de Opções

package com.exemplo.mod;

import com.rotacore.api.RotaCategory;
import com.rotacore.config.RotaConfigOption;
import net.minecraft.network.chat.Component;

public class OpcoesGeraisCategory extends RotaCategory {
    public OpcoesGeraisCategory() {
        super("geral", Component.translatable("meu_mod.category.geral"));

        // Adiciona um switch (liga/desliga)
        this.addOption(RotaConfigOption.createBoolean(
            "ativar_recurso",
            Component.translatable("meu_mod.opt.ativar"),
            Component.translatable("meu_mod.opt.ativar.desc"),
            true, // valor padrão
            val -> salvarConfig(val)
        ));

        // Adiciona um slider numérico
        this.addOption(RotaConfigOption.createIntSlider(
            "limite_distancia",
            Component.translatable("meu_mod.opt.distancia"),
            Component.translatable("meu_mod.opt.distancia.desc"),
            10, 100, 50, // min, max, default
            val -> atualizarDistancia(val)
        ));
    }
}

2. Widgets Modais Reutilizáveis

O Rota Core disponibiliza componentes modais prontos para uso:

  • ItemCatalogModalWidget: Abre uma janela interna com catálogo de todos os blocos e itens registrados no Minecraft com busca e seleção com 1 clique.
  • ConfirmModalWidget: Janela de confirmação para ações destrutivas (ex: restaurar padrões).
  • OptionPickerModalWidget: Seletor pop-up moderno para enums e listas.
