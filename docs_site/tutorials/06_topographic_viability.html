6. Viabilidade Topográfica e Geração de Mundo

O serviço que avalia a integridade do terreno e previne estruturas geradas em abismos.

O Problema das Vilas Deformadas no Minecraft

No Minecraft vanilla e com mods de estruturas adicionais, é comum encontrar vilas gerando cortadas por ravinas profundas, casas flutuando no ar sobre abismos ou hortas submersas no fundo de oceanos.

O SettlementViabilityService do Rota Core foi desenvolvido para resolver isso de raiz: ele intercepta a colocação de estruturas através de mixins nativos (StructurePlacementMixin) e faz uma amostragem matemática de altura (height sampling) do terreno.

Como Funciona a Avaliação de Viabilidade

  1. Desvio Padrão de Altura: Se a variação de Y dentro do envelope da vila for extrema (indicando penhasco ou desfiladeiro), a estrutura é rejeitada ou realocada.
  2. Filtro de Lâmina d'Água: Garante que estruturas terrestres não sejam geradas no meio de fossas oceânicas.
  3. Ancoragem Firme: Garante que os caminhos e fundações possuam solo contíguo antes de gerar.

Utilizando o Serviço de Viabilidade em Outros Mods

package com.exemplo.mod;

import com.rotacore.world.viability.SettlementViabilityService;
import net.minecraft.core.BlockPos;
import net.minecraft.world.level.LevelAccessor;

public class GeradorDePostoAvancado {
    public boolean podeGerarNesteLocal(LevelAccessor level, BlockPos pos) {
        // Avalia um raio de 32 blocos ao redor
        SettlementViabilityService.ViabilityResult resultado = 
            SettlementViabilityService.evaluateViability(level, pos, 32);

        if (!resultado.isViable()) {
            System.out.println("Local rejeitado pelo Rota Core: " + resultado.getReason());
            return false;
        }

        return true;
    }
}
