1. Início Rápido & Configuração no Gradle

Como integrar o Rota Core no seu ambiente de desenvolvimento NeoForge 1.21.1.

1. Adicionando a Dependência no build.gradle

Para criar um mod que se conecte ao Rota Core, declare a dependência no seu arquivo build.gradle:

repositories {
    mavenLocal()
    mavenCentral()
}

dependencies {
    // Adiciona o Rota Core na esteira de compilação
    implementation "com.rotacore:rota_core:1.5.0-dev.1"
}

2. Declarando no neoforge.mods.toml

Informe ao carregador de mods do Minecraft que o seu mod depende do Rota Core:

[[dependencies.seu_mod_id]]
    modId="rota_core"
    type="required"
    versionRange="[1.0.0,)"
    ordering="AFTER"
    side="BOTH"

3. Registrando seu Mod via RotaModule

Para que o Rota Core identifique seu mod e adicione sua aba no Hub central, implemente a interface RotaModule:

package com.exemplo.mod;

import com.rotacore.api.RotaModule;
import com.rotacore.api.RotaCoreRegistry;
import net.minecraft.network.chat.Component;
import net.minecraft.resources.ResourceLocation;

public class MeuModModule implements RotaModule {
    @Override
    public String getModuleId() {
        return "meu_mod";
    }

    @Override
    public Component getDisplayName() {
        return Component.translatable("meu_mod.title");
    }

    @Override
    public ResourceLocation getIcon() {
        return ResourceLocation.fromNamespaceAndPath("meu_mod", "textures/gui/icon.png");
    }
}

E registre-o na inicialização do cliente:

RotaCoreRegistry.registerModule(new MeuModModule());
